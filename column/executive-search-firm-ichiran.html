エグゼクティブサーチ会社は、企業から依頼を受けて役員・経営幹部の候補者を「指名で」探しに行く会社です。転職サイトに登録して待つ型とは逆で、候補者が自分から申し込む入口がほとんどありません。編集部の結論を先に書くと、役員を本気で目指す40〜50代が今すぐやるべきことは3つです。外資ビッグ5と日本の専業のどこが自分の層を扱っているかを知ること、サーチ会社の「ロングリスト」に載る状態を作ること、そしてサーチ会社と並行して登録型・スカウト型の入口も持つことです。

この記事では、外資ビッグ5（コーン・フェリー、エゴンゼンダー、スペンサースチュアート、ハイドリック＆ストラグルズ、ラッセル・レイノルズ）と、日本の専業5社（リクルートエグゼクティブエージェント、経営者JP、プロフェッショナルバンク、縄文アソシエイツ、サーチファーム・ジャパン）を、2026年10月20日に各社公式サイトで確認できた記載だけで整理しました。公式に数字がない項目は「公式に記載なし」と書いています。

リテイナー型と成功報酬型の違い：企業が払い、候補者は無料

サーチ会社の仕組みを知らないと、「登録したのに連絡が来ない」「なぜ自分に声がかかったのか分からない」で止まります。先にお金の流れを押さえてください。

リテイナー型（着手金型）：企業が先に払い、1社が専任で探す

リテイナー（retainer）型は、企業がサーチ会社に着手金を払い、サーチ会社が専任に近い体制で候補者を探す契約です。JACリクルートメントの解説では「着手金などを段階的に支払い、専任に近い体制で探索する。独占的に進める」とされています（JAC、2026年）。エゴンゼンダーは公式サイトで「固定料金制」を採り、その理由を「コンサルタントが利益相反に左右されず交渉に臨める」と説明しています（エゴンゼンダー公式、2026年10月20日確認）。

リテイナー型のサーチ会社は、採用が決まらなくても着手金を受け取っています。だから候補者を「早く決めるため」に押し込む動機が弱く、企業の要件に合う人を時間をかけて探せます。候補者から見ると、声がかかったときの精度が高いのがこの型です。一方で、サーチ会社は企業の代理人であって、候補者の代理人ではありません。報酬交渉で候補者側に立つわけではないと理解しておいてください。

成功報酬型（コンティンジェンシー型）：決まったときだけ払う

成功報酬型は、採用が決まった時点で企業が紹介手数料を払う契約です。初期費用がないため、企業は複数の会社に同時に依頼します。JACの解説でも「欧米ではリテイナー型が標準、日本では成功報酬型が依然として主流」と書かれています（JAC、2026年）。一般的な転職エージェントはこの型です。

日本の専業サーチ会社は、両方を組み合わせているところが多いのが実態です。リクルートエグゼクティブエージェントは公式に「成功報酬型人材紹介」「リテーナーサーチ」「社外取締役サーチ」の3つを並べています。経営者JPは「コンティンジェンシー」「クイック」「リテインド」「後継者」「CxO顧問」の各サーチを掲げています（いずれも公式、2026年10月20日確認）。つまり日本の専業は、サーチ型と登録型の両方の顔を持っています。

候補者は無料。ただし「お客様」でもない

どちらの型でも、費用を払うのは企業です。候補者が払うことはありません。これは職業安定法で、有料職業紹介事業者が求職者から手数料を取ることが原則禁止されているためです（職業安定法32条の3第2項。経営管理者など一部の職業で年収700万円超の場合に限り、例外として徴収できる定めがありますが、この記事で扱うサーチ会社はいずれも公式に候補者無料を前提にしています）。コトラも公式サイトで「登録から内定後のフォローまで無料。費用は求人企業側が負担する」と明記しています（コトラ公式、2026年10月20日確認）。

候補者にとって無料ですが、サーチ会社の顧客は企業です。候補者が「自分を売り込みたい」姿勢だけで接触すると、相手が求める情報（市場の動き、候補になりそうな人、自分の実績の事実）が出てこず、関係が続きません。編集部では、サーチ会社とは「情報を交換する相手」として付き合うのが長続きする形だと考えています。

外資ビッグ5：各社の公式記載と、候補者から見た使い方

外資大手5社は業界で「ビッグ5」と呼ばれ、JACの解説記事でも世界的な主要サーチファームとしてこの5社が挙げられています（JAC、2026年）。いずれもCEO・取締役・CxOクラスのサーチが中心で、リテイナー型が基本です。5社とも、候補者が「登録」する仕組みではなく、コンサルタントからの接触か、紹介・推薦で候補者プールに入る形です。

コーン・フェリー（Korn Ferry）

  • 130か国でのサーチ経験を公式に掲げ、Cレベル人材の採用で25年以上の実績をうたう（公式、2026年10月20日確認）
  • 対応ファンクションは12分野。会計、CFO、CHRO、法務、マーケティング、営業、サプライチェーン、サステナビリティ、テクノロジー責任者など機能トップが揃う
  • サーチの10ステップを公開。ディスカバリー → サクセス・プロファイル作成 → ターゲットリスト → 候補者選定 → 面談 → 提示 → 企業面接（最終2〜3名） → リファレンス → オファー → 完了

コーン・フェリーの公式ページで編集部が注目したのは「サクセス・プロファイル」と「最終2〜3名」の2点です。企業と一緒に「このポジションで成功する人の要件」を先に定義し、そこに当てはまる人をリストから絞って、企業に会わせるのは最終2〜3名です。候補者として声がかかった段階で、自分が最終何名の中にいるのかは聞いて構いません。

エゴンゼンダー（Egon Zehnder）

  • 創業約50年。公式サイトで「固定料金制」を明記し、利益相反を避ける仕組みとして説明（公式、2026年10月20日確認）

  • 「イコール・パートナーシップ」の組織体制。担当コンサルタントが責任を持ちつつ、クライアントは全コンサルタントの知見とネットワークを使える

エゴンゼンダーの公式サイトにあるサーチの進め方は6段階です。理想の候補者の定義 → 候補者の発掘（専属リサーチチームが独自データベースで調査） → 候補者の評価（コンピテンシーとポテンシャルの評価モデル） → 候補者へのアプローチ → 採用交渉 → 着任後の定着支援。最後の定着支援では、最初の90日間に周囲からの第一印象のフィードバックを集め、新任者と定期的に面談すると書かれています。

候補者として見るべき点は「ポテンシャル評価」です。経歴上の大きな転機を掘り下げて、組織や文化への適応度を見るとされています。過去の肩書きの並びより、「転機で何を選び、どう動いたか」を語れる準備が要ります。

ロングリスト → ショートリスト → 最終2〜3名：サーチの流れと、あなたがどこにいるか

サーチ会社が動くとき、候補者は次の順で絞られます。コーン・フェリーの10ステップ（公式、2026年10月20日確認）をもとに、候補者側から見た位置を整理します。

  1. 要件定義（ディスカバリー、サクセス・プロファイル）：企業とサーチ会社が「どんな人が成功するか」を決める。候補者はまだ登場しない
  2. ロングリスト（ターゲットリスト）：データベース、独自ルート、SNS、業界団体から候補者名を集める。ここで数十〜百名規模になることが多い。この段階で名前が挙がるかどうかが、すべての分かれ目
  3. 候補者への接触：リストの中から「職務との適合性と転職意向」を確認する。ヘッドハンティングの電話が来るのはここ（ヘッドハンティングの電話が来たときの対応）
  4. ショートリスト（面談・評価）：サーチ会社のコンサルタントが面談し、評価レポートを作る。ここで数名に絞られる
  5. 企業面接（最終2〜3名）：企業が面接し、最終候補を2〜3名に絞る
  6. リファレンスチェック → オファー → 完了：前職への確認、報酬・条件の構築、受諾後のオンボーディング

候補者が自分で動かせるのは2番のロングリストに載るところまでです。3番以降は、サーチ会社が企業の要件に照らして判断します。「連絡が来たのに次に進まなかった」のは、あなたの価値が低いからではなく、要件（業界・規模・フェーズ・報酬）と合わなかったことがほとんどです。

ロングリストに載るのに必要なのは、「業界で名前が挙がる実績」と「その実績が検索・紹介で見つかる状態」の2つです。社内で評価されていても、外から見えなければリストに載りません。

サーチ会社に「見つけてもらう」5つの方法

サーチ会社は候補者を募集しません。だから、見つけてもらう状態を自分で作ります。編集部で見てきた範囲で、効いている順に並べます。

1. 日本の専業に、自分から登録・相談する

プロフェッショナルバンクには「ヘッドハンティング登録する（無料）」、経営者JPには「転職のご相談」「エントリー」「KEIEISHA TERRACE無料会員」、リクルートエグゼクティブエージェントには「個人の方のお問い合わせ」の導線が公式にあります（いずれも2026年10月20日確認）。外資ビッグ5には公式の登録導線がありません。まず日本の専業3社に自分の存在を知らせるのが、最も直接的な方法です。

2. スカウト型サイトで、ヘッドハンターの目に触れる

ビズリーチには登録ヘッドハンターが9,500人以上（2026年7月末時点）、doda Xにはヘッドハンター約7,400人（2026年7月時点）います（各社公式）。サーチ会社のコンサルタントや、サーチ会社と連携する個人ヘッドハンターが、ここで候補者を探しています。職務経歴書に「事業・PL責任」「経営会議での役割」「組織の規模」を数字で書いておくと、ロングリスト作りの検索に引っかかります（役員候補の職務経歴書の書き方）。

3. 業界団体・カンファレンスでの登壇、寄稿

コーン・フェリーはターゲットリストの情報源として「SNS、業界団体」を公式に挙げています。業界団体の委員、カンファレンスの登壇、業界誌への寄稿は、サーチ会社のリサーチャーが名前を拾う経路そのものです。JACの解説でも、サーチ対象になるために「社外での専門性の発信」が有効とされています（JAC、2026年）。

合わない案件を断るのは当然です。ただ、「なぜ合わないか」「どんな案件なら動くか」「心当たりの人」を返すと、サーチ会社のデータベースに「反応がある候補者」として残ります。何も返さない人は、次のロングリストから外れます。

サーチ会社を使うときの注意点：候補者が誤解しやすい3つ

サーチ会社はあなたの代理人ではない

繰り返しになりますが、費用を払うのは企業です。報酬交渉でサーチ会社は「企業と候補者の双方に助言する」（エゴンゼンダー公式）立場で、候補者の代理人として企業と戦うわけではありません。年収交渉は自分で論点を持つ必要があります（役員の年収交渉の進め方）。

役員の転職には会社法の制約がある

現職で取締役の人は、在任中は競業取引に株主総会（取締役会設置会社では取締役会）の承認が必要です（会社法356条）。退任後は原則として356条の制限はかかりませんが、会社との個別の競業避止合意がある場合は別です。サーチ会社に声をかけられた段階で、自分の競業避止の範囲を確認しておいてください（役員の競業避止義務と転職）。

リファレンスチェックは必ず入る

コーン・フェリーの10ステップでも、企業面接の後にリファレンスチェックが入ります。前職・現職の上司や同僚に照会が行きます。「誰に照会してもらうか」を自分で用意できる状態にしておくのが、役員候補の準備です。

FAQ：エグゼクティブサーチ会社について聞かれること

Q. サーチ会社に登録料や相談料はかかりますか

Q. 外資ビッグ5に自分から連絡しても意味がありますか

Q. リテイナー型と成功報酬型、候補者にとってどちらが良いですか

リテイナー型は案件の精度が高く、企業が本気で探しているポジションです。成功報酬型は案件の数が多く、複数のエージェントから同じ求人が来ることがあります。候補者はどちらも無料なので、両方と付き合うのが正解です。

Q. ヘッドハンティングの連絡がSMSで来ました。本物ですか

スペンサースチュアートは公式サイトで、同社を騙ったSMSが出回っていると注意喚起しています。エンワールドも2025年10月に社員を装ったSMSへの注意を掲載しています（各社公式、2026年10月20日確認）。公式サイトの連絡先に照会してから返事をしてください。

Q. 声がかかったが、今の会社に知られませんか

サーチ会社は守秘を前提に動きます。エゴンゼンダーは「守秘性を保ちながら候補者を探す」と公式に書いています。ただし、リファレンスチェックの段階では現職・前職への照会が入るため、その時点で誰に照会してもらうかは自分で決めてください。
